network in Cisco Packet Tracer for an assigned client scenario.

## Client Summary

**Kamogelo Insurance Brokers** is a Professional Services organisation based
in Vryburg. The brief requires a network built around the assigned address
block `192.168.40.0/24`, with:

- Appropriate connectivity and network services for a small brokerage office
- A **design constraint**: the boardroom requires dedicated wired and
  wireless presentation ports
- A **change request (CR15)**: a second Internet connection added for
  resilience, which must be integrated into the design
- An assigned **networking challenge**: Wireless LAN (AP integration &
  coverage) — Foundational difficulty
